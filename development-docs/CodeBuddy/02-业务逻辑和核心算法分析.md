## 二、核心算法详解

### 2.1 音视频绝对同步算法

#### 问题描述
传统方案中，先生成视频再生成配音，容易出现：
- 配音时长与视频时长不匹配
- 视频画面节奏与旁白脱节
- 需要手动调整剪辑

#### 解决方案：TTS 优先策略

```python
# modules/tts.py
def get_audio_duration(audio_path: str) -> float:
    """精确测量音频时长（毫秒级）"""
    import subprocess
    cmd = [
        "ffprobe",
        "-v", "quiet",
        "-show_entries", "format=duration",
        "-of", "csv=p=0",
        audio_path
    ]
    result = subprocess.run(cmd, capture_output=True, text=True)
    return float(result.stdout.strip())

def update_scene_durations(scenes: list[Scene], voiceover_results: dict[int, tuple[str, float]]) -> list[Scene]:
    """用 TTS 时长更新分镜 duration"""
    for scene in scenes:
        if scene.scene_id in voiceover_results:
            audio_path, duration = voiceover_results[scene.scene_id]
            # 添加 0.5 秒缓冲，避免视频太短
            scene.duration = duration + 0.5
    return scenes
```

#### 核心优势
1. **精确同步**: 先生成 TTS，精确测量时长，再按时长生成视频
2. **自然节奏**: 视频长度匹配配音语速，无需手动裁剪
3. **成本可控**: 避免因时长不匹配导致的重生成

### 2.2 关键帧锁定策略

#### 问题描述
图生视频容易出现：
- 画面主体漂移
- 角色外貌不一致
- 细节丢失

#### 解决方案：Nano Banana 首帧锁定

```python
# modules/image_gen.py
async def generate_keyframe(scene: Scene, reference_images: list[str]) -> str:
    """生成高质量首帧关键图"""

                 "Character must look like SAME PERSON in different scene."
        ))

    # 2. 添加主提示词 + 质量提示词
    full_prompt = (
        f"{scene.image_prompt}, "
        f"ultra high quality, 1080P resolution, "
        f"cinematic composition, sharp focus, detailed"
    )
    contents.append(types.Part.from_text(text=full_prompt))

    # 3. 调用 Gemini 生成 4K 关键帧
    response = client.models.generate_content(
        model=config.image_gen.model,
        contents=contents,

        if part.inline_data:
            with open(output_path, "wb") as f:
                f.write(part.inline_data.data)
            break

    return output_path
```

#### 核心优势
1. **高保真**: 4K 关键帧保证画面质量
2. **角色一致**: 参考图注入确保角色统一
3. **主体锁定**: 首帧作为视频第一帧，避免漂移

### 2.3 智能引擎路由算法

#### 问题描述
不同视频生成引擎各有优势：
- **Kling**: 动作场景、运动镜头、快速切换
- **Seedance**: 口型同步、多角色、对话场景
- **手动选择**: 用户难以判断最优选择

#### 解决方案：关键词评分路由

```python
# modules/video_gen.py
def smart_route_engine(scene: Scene, default: str = "kling") -> str:
    """
    根据场景内容智能选择视频引擎

    规则:
    - 对话/口型同步 → Seedance
    - 多人/多角色 → Seedance
    - 动作/运动/体育 → Kling
    - 其他 → 默认引擎
    """
    # Seedance 优势关键词
    seedance_keywords = [
        "talking", "speaking", "dialogue", "conversation",
        "lip sync", "multiple characters", "crowd", "group",
        "people talking", "interview", "narration",
        "说话", "对话", "多人", "人群", "口型"
    ]

    # Kling 优势关键词
    kling_keywords = [
        "action", "running", "jumping", "sports",
        "explosion", "fast", "dynamic", "energetic",
        "chase", "fight", "dance", "运动", "奔跑", "跳跃"
    ]

    # 提取提示词
    prompt_lower = (scene.video_prompt + " " + " ".join(scene.style_tags)).lower()

    # 关键词匹配评分
    seedance_score = sum(1 for kw in seedance_keywords if kw in prompt_lower)
    kling_score = sum(1 for kw in kling_keywords if kw in prompt_lower)

    # 路由决策
    if seedance_score > kling_score:
        return "seedance"
    elif kling_score > seedance_score:
        return "kling"
    else:
        return default
```

#### 核心优势
1. **自动选择**: 无需手动判断，系统自动选择最优引擎
2. **成本优化**: 避免使用不适合的引擎浪费成本
3. **质量提升**: 每个场景使用最擅长该类型的引擎

### 2.4 shot_mode 自动判断算法

#### 问题描述
Kling Omni 支持多种生成模式，需要根据场景选择：
- **multi_ref**: 多参考图模式（角色一致性最强）
- **first_end_frame**: 首尾帧控制（场景转换）
- **t2v**: 文生视频（纯风景）
- **i2v**: 传统图生视频（默认）

#### 解决方案：规则引擎

```python
# modules/video_gen.py
def auto_detect_shot_mode(scene: Scene) -> ShotMode:
    """
    根据分镜内容自动判断最优生成模式

    判断规则:
    1. 有角色参考图 + 动作场景 → multi_ref
    2. 转场/运镜/过渡关键词 → first_end_frame
    3. 纯风景/氛围/无人物 → t2v
    4. 其他 → i2v (默认)
    """
    # 场景已有 shot_mode，直接使用
    if hasattr(scene, "shot_mode") and scene.shot_mode:
        return scene.shot_mode

    prompt_lower = (
        scene.video_prompt + " " +
        scene.image_prompt + " " +
        " ".join(scene.style_tags)
    ).lower()

    # 规则 1: 有角色参考图 → multi_ref
    if scene.reference_character:
        return "multi_ref"

    # 规则 2: 转场/运镜关键词 → first_end_frame
    transition_keywords = [
        "transition", "morph", "transform", "cut to",
        "fade to", "time lapse", "timelapse", "dissolve",
        "转场", "过渡", "变换", "延时", "时光流逝"
    ]
    if any(kw in prompt_lower for kw in transition_keywords):
        return "first_end_frame"

    # 规则 3: 纯风景/氛围 → t2v
    landscape_keywords = [
        "landscape", "scenery", "nature", "sky", "ocean",
        "mountain", "forest", "sunset", "sunrise", "aerial",
        "drone", "风景", "自然", "天空", "航拍"
    ]
    person_keywords = [
        "person", "people", "man", "woman", "character",
        "figure", "人物", "人", "角色", "主角"
    ]

    has_landscape = any(kw in prompt_lower for kw in landscape_keywords)
    has_person = any(kw in prompt_lower for kw in person_keywords)

    if has_landscape and not has_person:
        return "t2v"

    # 规则 4: 默认 → i2v
    return "i2v"
```

#### 核心优势
1. **自动化**: 无需手动标注 shot_mode
2. **质量优化**: 每个场景使用最适合的生成模式
3. **成本节约**: 避免使用不必要的多参考图模式

### 2.5 FFmpeg xfade 转场拼接算法

#### 问题描述
多个视频片段拼接需要：
- 平滑过渡
- 音画同步
- 分辨率统一

#### 解决方案：xfade 滤镜链

```python
# modules/assembler.py
def _merge_with_transitions(
    clips: list[str],
    transitions: list[str],
    output_path: str,
    transition_duration: float = 0.5
) -> None:
    """使用 xfade 滤镜拼接视频（带转场）"""

    if len(clips) == 1:
        # 只有一个片段，直接复制
        import shutil
        shutil.copy2(clips[0], output_path)
        return

    # 构建 FFmpeg 复杂滤镜链
    filter_complex = []

    # 每个片段的输入标签
    inputs = []
    for i, clip in enumerate(clips):
        inputs.extend(["-i", clip])

    # 构建 xfade 滤镜链
    # 格式: [0:v][1:v]xfade=transition=fade:duration=0.5:offset=4.5[v1]
    # offset = 第一个片段时长 - 转场时长
    offset = 5.0 - transition_duration  # 假设每个片段 5 秒

    for i in range(len(clips) - 1):
        if i == 0:
            # 第一个 xfade
            filter_complex.append(
                f"[{i}:v][{i+1}:v]xfade="
                f"transition={transitions[i]}:"
                f"duration={transition_duration}:"
                f"offset={offset}[v{i+1}]"
            )
        else:
            # 后续 xfade
            filter_complex.append(
                f"[v{i}][{i+1}:v]xfade="
                f"transition={transitions[i]}:"
                f"duration={transition_duration}:"
                f"offset={offset * (i+1)}[v{i+1}]"
            )

    # FFmpeg 命令
    cmd = [
        "ffmpeg", "-y",
        *inputs,
        "-filter_complex", ";".join(filter_complex),
        "-map", f"[v{len(clips)-1}]",
        "-c:v", "libx264",
        "-preset", "fast",
        "-crf", "18",
        "-pix_fmt", "yuv420p",
        output_path
    ]

    subprocess.run(cmd, check=True)
```

#### 核心优势
1. **平滑过渡**: xfade 滤镜支持多种转场效果
2. **精确控制**: 可自定义转场时长和类型
3. **高质量**: 使用 libx264 编码，保持画面质量

### 2.6 音频混合同步算法

#### 问题描述
多段音频混合需要：
- 精确时间对齐
- 考虑转场重叠
- 音量平衡

#### 解决方案：amix 滤镜 + 偏移量计算

```python
# modules/assembler.py
def _mix_audio_aligned(
    video_path: str,
    audio_clips: list[str],
    scene_durations: list[float],
    transition_duration: float = 0.5,
    output_path: str = None
) -> None:
    """混合多段音频，精确对齐时间轴"""

    if not audio_clips:
        return

    # 计算每段音频的起始时间偏移
    offsets = [0.0]
    for i in range(1, len(scene_durations)):
        # 累计时长，减去转场重叠
        offset = offsets[-1] + scene_durations[i-1] - transition_duration
        offsets.append(offset)

    # 构建 amix 滤镜
    # 格式: [0:a][1:a]amix=inputs=2:duration=first:dropout_transition=0
    filter_complex = []

    # 延迟每段音频到正确位置
    for i, (audio_path, offset) in enumerate(zip(audio_clips, offsets)):
        filter_complex.append(f"[{i}:a]adelay={int(offset*1000)}|{int(offset*1000)}[a{i}]")

    # 混合所有音频
    mix_inputs = ":".join([f"[a{i}]" for i in range(len(audio_clips))])
    filter_complex.append(
        f"{mix_inputs}amix=inputs={len(audio_clips)}:duration=first:dropout_transition=0[aout]"
    )

    # FFmpeg 命令
    cmd = [
        "ffmpeg", "-y",
        "-i", video_path,
        *[f"-i" if clip else "" for clip in audio_clips if clip],
        "-filter_complex", ";".join(filter_complex),
        "-map", "0:v",
        "-map", "[aout]",
        "-c:v", "copy",
        "-c:a", "aac",
        "-b:a", "192k",
        output_path or video_path
    ]

    subprocess.run(cmd, check=True)
```

#### 核心优势
1. **精确对齐**: adelay 滤镜精确到毫秒
2. **无缝衔接**: 考虑转场重叠，避免音频突兀
3. **音量平衡**: amix 自动平衡多轨音频

### 2.7 SRT 字幕生成算法

#### 问题描述
字幕需要：
- 准确的时间戳
- 对应的文本内容
- 符合 SRT 格式标准

#### 解决方案：时间轴映射

```python
# modules/assembler.py
def _generate_srt(scenes: list[Scene], audio_clips: dict[int, str], output_path: str) -> None:
    """生成 SRT 字幕文件"""

    # 读取每段音频的实际时长
    durations = {}
    for scene_id, audio_path in audio_clips.items():
        durations[scene_id] = get_audio_duration(audio_path)

    # 计算时间轴
    current_time = 0.0
    srt_lines = []

    for i, scene in enumerate(scenes, 1):
        # 时间格式: HH:MM:SS,mmm
        start = _format_srt_time(current_time)
        duration = durations.get(scene.scene_id, scene.duration)
        end = _format_srt_time(current_time + duration)

        # SRT 格式
        srt_lines.append(f"{i}")
        srt_lines.append(f"{start} --> {end}")
        srt_lines.append(scene.voiceover)
        srt_lines.append("")

        current_time += duration

    # 写入文件
    with open(output_path, "w", encoding="utf-8") as f:
        f.write("\n".join(srt_lines))

def _format_srt_time(seconds: float) -> str:
    """将秒数格式化为 SRT 时间格式"""
    hours = int(seconds // 3600)
    minutes = int((seconds % 3600) // 60)
    secs = int(seconds % 60)
    millis = int((seconds % 1) * 1000)
    return f"{hours:02d}:{minutes:02d}:{secs:02d},{millis:03d}"
```

#### 核心优势
1. **准确时间**: 使用 TTS 实际时长，避免字幕错位
2. **标准格式**: 符合 SRT 规范，兼容性好
3. **易编辑**: 纯文本格式，用户可手动修改

### 2.8 记忆学习算法

#### 问题描述
如何让系统记住用户的风格偏好，下次生成时自动应用？

#### 解决方案：多维度特征提取 + 向量存储

```python
# modules/memory.py
class MemoryManager:
    """记忆管理器 - 学习用户风格偏好"""

    def learn_from_script(self, script: dict, project_id: str) -> None:
        """从脚本中学习风格特征"""
        # 1. 提取风格标签
        style_tags = []
        for scene in script.get("scenes", []):
            style_tags.extend(scene.get("style_tags", []))

        # 2. 提取转场偏好
        transition_counts = {}
        for scene in script.get("scenes", []):
            transition = scene.get("transition", "crossfade")
            transition_counts[transition] = transition_counts.get(transition, 0) + 1

        # 3. 提取运镜偏好
        camera_counts = {}
        for scene in script.get("scenes", []):
            camera = scene.get("camera_motion", "static")
            camera_counts[camera] = camera_counts.get(camera, 0) + 1

        # 4. 保存到记忆系统
        memory = {
            "project_id": project_id,
            "style_tags": style_tags,
            "transition_preference": max(transition_counts, key=transition_counts.get),
            "camera_preference": max(camera_counts, key=camera_counts.get),
            "avg_scene_duration": sum(s["duration"] for s in script["scenes"]) / len(script["scenes"]),
        }

        if self.config.memory.provider == "mem0_cloud":
            self._save_to_mem0_cloud(memory)
        else:
            self._save_to_local(memory)

    def build_context_for_generation(self, topic: str) -> str:
        """为生成任务构建记忆上下文"""
        if not self.config.memory.enabled:
            return ""

        # 1. 查询历史偏好
        memories = self._query_recent_memories(limit=10)

        # 2. 构建上下文
        context_parts = []
        for mem in memories:
            context_parts.append(
                f"风格偏好: {', '.join(mem.get('style_tags', []))}, "
                f"常用转场: {mem.get('transition_preference', 'crossfade')}, "
                f"常用运镜: {mem.get('camera_preference', 'static')}"
            )

        # 3. 提取高频标签
        all_tags = []
        for mem in memories:
            all_tags.extend(mem.get("style_tags", []))

        from collections import Counter
        top_tags = [tag for tag, _ in Counter(all_tags).most_common(5)]

        # 4. 组合成提示词
        context = f"""
基于历史项目，用户的风格偏好如下:
- 高频风格标签: {', '.join(top_tags)}
- 偏好转场: {memories[0].get('transition_preference', 'crossfade') if memories else 'crossfade'}
- 偏好运镜: {memories[0].get('camera_preference', 'static') if memories else 'static'}
- 平均分镜时长: {memories[0].get('avg_scene_duration', 5) if memories else 5} 秒

请在生成新视频时参考这些偏好，但也要根据新主题灵活调整。
""".strip()

        return context

    def learn_from_rating(self, project_id: str, rating: int) -> None:
        """从用户评分中学习"""
        # 高分 (4-5 星): 强化当前风格
        if rating >= 4:
            self._reinforce_style(project_id)
        # 低分 (1-2 星): 弱化当前风格
        elif rating <= 2:
            self._weaken_style(project_id)
```

#### 核心优势
1. **持续学习**: 每次生成后自动提取特征
2. **个性化**: 越用越懂用户
3. **多维度**: 风格标签、转场、运镜、时长等

```python
async def analyze_reference_video_sync(video_path: str, config: PilipiliConfig) -> ReferenceVideoAnalysis:

   - characters_in_scene (本分镜出现的角色 ID)
7. BGM 风格描述
8. 色调/调色风格
9. 整体风格提示词（用于生成同风格视频）
10. 每个分镜的反推提示词（英文，可直接用于复现）

请严格按照 JSON 格式输出，不要有任何额外文字。
"""

    # 3. 调用 Gemini 视频理解
    response = client.models.generate_content(
        model="gemini-2.0-flash-exp",
        contents=[
            types.Part.from_text(text=prompt),
            types.Part.from_bytes(
                data=base64.b64decode(video_base64),
                mime_type="video/mp4"
            )
        ]
    )

    # 4. 解析 JSON 响应
    import json
    result_text = response.candidates[0].content.parts[0].text
    result = json.loads(result_text)

    # 5. 构建分析结果对象
    analysis = ReferenceVideoAnalysis(
        title=result["title"],
        style=result["style"],
        aspect_ratio=result["aspect_ratio"],
        total_duration=result["total_duration"],
        characters=[
            CharacterInfo(**char) for char in result["characters"]
        ],
        scenes=[
            Scene(**scene) for scene in result["scenes"]
        ],
        bgm_style=result["bgm_style"],
        color_grade=result["color_grade"],
        overall_prompt=result["overall_prompt"],
        reverse_prompts=result["reverse_prompts"],
        raw_analysis=result_text
    )

    return analysis
```

2. **反推提示词**: 生成可直接复用的英文提示词
3. **一键复刻**: 基于分析结果直接生成相似视频

```python
# api/server.py
class ConnectionManager:
    """WebSocket 连接管理器"""

    def __init__(self):
        self.connections: dict[str, list[WebSocket]] = {}

    async def connect(self, project_id: str, websocket: WebSocket):
        await websocket.accept()
        if project_id not in self.connections:
            self.connections[project_id] = []
        self.connections[project_id].append(websocket)

    def disconnect(self, project_id: str, websocket: WebSocket):
        if project_id in self.connections:
            try:
                self.connections[project_id].remove(websocket)
            except ValueError:
                pass

    async def broadcast(self, project_id: str, message: dict):
        """向项目的所有 WebSocket 连接广播消息"""
        if project_id in self.connections:
            dead = []
            for ws in self.connections[project_id]:
                try:
                    await ws.send_json(message)
                except Exception:
                    dead.append(ws)
            for ws in dead:
                try:
                    self.connections[project_id].remove(ws)
                except ValueError:
                    pass
```
