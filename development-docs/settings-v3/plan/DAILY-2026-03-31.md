### 1. API Key 加密存储
**文件**: `api/config_db_v3.py`

**问题**: 之前保存的 API Key 是明文，读取时尝试解密会失败。

**修复**:
- 添加 `encrypt_value()` 和 `decrypt_value()` 函数
- 使用 XOR + base64 简单加密
- `save_user_provider_config()` 保存时自动加密
- `decrypt_value()` 兼容明文存储的旧数据（解密失败时返回原值）

**技术细节**:
```python
def _get_xor_cipher(text: str, key: str) -> str:
    result = []
    for i, c in enumerate(text):
        key_c = key[i % len(key)]
        result.append(chr(ord(c) ^ ord(key_c)))
    return ''.join(result)

def encrypt_value(value: Optional[str]) -> Optional[str]:
    if not value:
        return None
    try:
        cipher = _get_xor_cipher(value, _encryption_key)
        return base64.b64encode(cipher.encode()).decode()
    except Exception:
        return None

def decrypt_value(encrypted: Optional[str]) -> Optional[str]:
    if not encrypted:
        return None
    try:
        cipher = base64.b64decode(encrypted.encode()).decode()
        return _get_xor_cipher(cipher, _encryption_key)
    except Exception:
        # 兼容明文存储的旧数据
        return encrypted
```

### 2. 模型列表自动获取
**文件**: `api/config_api_v3.py`

**功能**: 从提供商 API 自动获取可用模型列表，缓存 7 天。

**端点**: `GET /api/v3/providers/{provider_id}/models-from-api?refresh=true`

**支持的提供商**:
- DeepSeek, Kimi, MiniMax, OpenRouter, Ollama, 阿里云, 火山引擎（OpenAI 兼容）
- Gemini（特殊格式）

**实现细节**:
- 文件缓存: `data/config/model_cache.json`
- 缓存键: `models:{provider_id}:{user_id}`
- 缓存有效期: 7 天
- 支持强制刷新: `?refresh=true` 参数

## 遇到的技术问题

### 问题1: 模型列表返回 0 个模型
**现象**: `[模型列表API] API Key 获取成功: False`

**原因**: `decrypt_value` 解密明文存储的旧数据失败

**解决**: `decrypt_value` 兼容明文（解密失败返回原值）

### 问题2: OpenRouter 测试失败 (401)
**现象**: `API Key 无效或已过期 (401)`

**原因**: OpenRouter 要求特殊的身份验证头：
- `Referer`: 站点来源
- `X-Title`: 应用名称

**解决**: 专用 `_test_openrouter` 函数添加必需头
