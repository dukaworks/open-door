## 一、核心设计理念

### 用户视角的三层需求

| 层级         | 用户画像           | 操作复杂度   | 特征                       |
| ------------ | ------------------ | ------------ | -------------------------- |
| **小白模式** | 首次使用，不懂技术 | ⭐ (1-2步)   | 选择套餐 → 配置 Key → 开始 |
| **进阶模式** | 有经验，想微调     | ⭐⭐ (3-5步) | 选套餐 → 调参数 → 保存     |
| **高级模式** | 开发者/极客        | ⭐⭐⭐       | 完全自定义 + 限额管理      |

### 设计原则

1. **套餐优先** - 80% 用户应该像"买手机选套餐"一样简单
2. **渐进披露** - 专业技术词汇只在高级模式显示
3. **即时反馈** - 配置 Key 后立即测试，提示成功/失败
4. **可跳过** - 暂时不配置也能用（使用系统默认值）

### 4.3.1 模型列表自动获取 + 缓存

**逻辑：**

| 场景             | 行为                          |
| ---------------- | ----------------------------- |
| 首次选择提供商   | 自动调用厂商 API 获取模型列表 |
| 再次选择         | 使用缓存（秒开，无需等待）    |
| 点击 [刷新] 按钮 | 重新获取最新模型列表          |
| 缓存超过 24 小时 | 静默后台刷新                  |

**缓存存储：**

```python
# SQLite 表结构
CREATE TABLE model_cache (
    provider TEXT NOT NULL,
    models_json TEXT NOT NULL,  -- 模型列表 JSON
    cached_at TIMESTAMP NOT NULL,
    PRIMARY KEY (provider)
);
```

**后端实现：**

```python
@app.get("/api/providers/{provider}/models")
async def get_provider_models(
    provider: str,
    refresh: bool = False  # ?refresh=true 强制刷新
):
    # 1. 检查缓存（除非强制刷新）
    if not refresh:
        cached = db.get_model_cache(provider)
        if cached and (now - cached.cached_at).hours < 24:
            return cached.models

    # 2. 调用厂商 API 获取模型列表
    models = await fetch_models_from_provider(provider)

    # 3. 存入缓存
    db.save_model_cache(provider, models)
```

### 5.2 API Key 配置卡片 (ServiceCard)

```tsx
interface ServiceCardProps {
  serviceType: "llm" | "video" | "tts" | "image" | "memory";
  serviceName: string; // "文案大脑"
  providerName: string; // "DeepSeek"
  docsUrl: string; // 获取 Key 的文档链接
  required: boolean; // 是否必须配置
  isConfigured: boolean; // 是否已配置
  onTest: () => void; // 测试连接
  onSave: (key: string, secret?: string) => void; // 保存
}

function ServiceCard({
  serviceType,
  serviceName,
  providerName,
  docsUrl,
  required,
  isConfigured,
  onTest,
  onSave,
}: ServiceCardProps) {
  // 状态
  const [apiKey, setApiKey] = useState("");
  const [apiSecret, setApiSecret] = useState("");
  const [testStatus, setTestStatus] = useState<
    "idle" | "testing" | "success" | "error"
  >("idle");
  const [errorMessage, setErrorMessage] = useState("");

  // 测试连接
  const handleTest = async () => {
    setTestStatus("testing");
    try {
      const result = await testApiKey(serviceType, apiKey);
      if (result.success) {
        setTestStatus("success");
      } else {
        setTestStatus("error");
        setErrorMessage(result.message);
      }
    } catch {
      setTestStatus("error");
      setErrorMessage("连接失败");
    }
  };

  return (
    <div className="service-card">
      <div className="service-header">
        <span className="service-icon">{getServiceIcon(serviceType)}</span>
        <span className="service-name">{serviceName}</span>
        <span
          className={`status-badge ${isConfigured ? "configured" : "unconfigured"}`}
        >
          {isConfigured ? "✅ 已配置" : "未配置"}
        </span>
      </div>

      {/* API Key 输入 */}
      <div className="input-group">
        <label>API Key</label>
        <input
          type="password"
          value={apiKey}
          onChange={e => setApiKey(e.target.value)}
          placeholder="粘贴你的 API Key"
        />
      </div>

      {/* API Secret（仅 Kling 需要）*/}
      {serviceType === "video" && (
        <div className="input-group">
          <label>API Secret</label>
          <input
            type="password"
            value={apiSecret}
            onChange={e => setApiSecret(e.target.value)}
            placeholder="粘贴你的 API Secret"
          />
        </div>
      )}

      {/* 操作按钮 */}
      <div className="actions">
        <a href={docsUrl} target="_blank" className="docs-link">
          如何获取？ →
        </a>
        <button
          onClick={handleTest}
          disabled={!apiKey || testStatus === "testing"}
        >
          {testStatus === "testing" ? "测试中..." : "测试连接"}
        </button>
        <button onClick={() => onSave(apiKey, apiSecret)} disabled={!apiKey}>
          保存
        </button>
      </div>

      {/* 状态反馈 */}
      {testStatus === "success" && (
        <div className="status-message success">✅ 连接成功</div>
      )}
      {testStatus === "error" && (
        <div className="status-message error">❌ {errorMessage}</div>
      )}
    </div>
  );
}
```

### 5.3 引导流程 (SetupWizard)

```tsx
function SetupWizard() {
  const [step, setStep] = useState<"package" | "config" | "complete">(
    "package"
  );
  const [selectedPackage, setSelectedPackage] = useState<string>("");

  // Step 1: 选择套餐
  if (step === "package") {
    return (
      <div className="setup-wizard">
        <h1>欢迎使用 Open-Door</h1>
        <p>请选择一个适合你的套餐</p>

        <div className="packages-grid">
          {packages.map(pkg => (
            <button
              key={pkg.id}
              className="package-card"
              onClick={() => {
                setSelectedPackage(pkg.id);
                setStep("config");
              }}
            >
              <span className="icon">{pkg.icon}</span>
              <span className="name">{pkg.name}</span>
              <span className="desc">{pkg.description}</span>
            </button>
          ))}
        </div>

        <a onClick={() => setStep("config")}>我需要自定义配置 →</a>
      </div>
    );
  }

  // Step 2: 配置 API Key
  if (step === "config") {
    const pkg = packages.find(p => p.id === selectedPackage);
    return (
      <div className="api-config">
        <h2>配置 API 授权</h2>
        <p>你选择了「{pkg?.name}」套餐，需要配置以下服务</p>

        {pkg?.services.map(service => (
          <ServiceCard
            key={service.type}
            serviceType={service.type}
            serviceName={getServiceName(service.type)}
            providerName={service.provider}
            docsUrl={getDocsUrl(service.type)}
            required={service.required}
            onSave={handleSave}
            onTest={handleTest}
          />
        ))}

        <div className="footer-actions">
          <button onClick={() => setStep("complete")}>保存并开始使用</button>
        </div>
      </div>
    );
  }

  // Step 3: 完成
  return <div className="setup-complete">开始你的创作之旅！</div>;
}
```

### 6.5 API 聚合服务商支持

**设计要点：**

| 特性                | 说明                                         |
| ------------------- | -------------------------------------------- |
| **Base URL 可配置** | 用户可自定义 API 地址，支持代理/反向代理     |
| **模型名称自定义**  | 支持任何 OpenAI 兼容格式（如 openai/gpt-4o） |
| **聚合商预设**      | 预置 OpenRouter、OneAPI 等常见聚合商模板     |

**支持的提供商类型：**

| 类型           | 示例                  | 特点                  |
| -------------- | --------------------- | --------------------- |
| **官方直连**   | DeepSeek、Kimi、Kling | 官方 API，直接连接    |
| **API 聚合**   | OpenRouter、OneAPI    | 一个 Key 访问多个模型 |
| **本地部署**   | Ollama、LM Studio     | 本地模型，无需网络    |
| **自定义代理** | 用户自建网关          | 通过代理访问官方 API  |
