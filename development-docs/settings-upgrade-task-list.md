- [ ] `GET /api/providers` - 获取支持的所有提供商

- [ ] `GET /api/user/config` - 获取用户配置
- [ ] `POST /api/user/config` - 保存用户配置
- [ ] `POST /api/user/config/test` - 测试配置有效性
